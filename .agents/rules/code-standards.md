# Code Standards & Quality Guidelines

## Language & Runtime: .NET / C# Uygulaması

### C# / .NET Standards
- **Naming Conventions**: İsimlendirme yaparken kurallara uy (örn. sınıflar için PascalCase).
- **Nullable Reference Types**: Değişkenlerin boş (null) gelme ihtimalini kontrol et, uygulama çökmesin.

### Global Quality Mandates
- **No Dead Code**: Kullanılmayan kodları ve deneme (debug) mesajlarını projede bırakma.
